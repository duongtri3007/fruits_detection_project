# AI Object Recognition Project

## 🌟 Highlights
- Developed an AI model capable of recognizing objects in images.
- Built with Python 3 and organized with a clean and easy-to-understand project structure.
- Designed as an introductory project for learning Artificial Intelligence.

## Overview
This project creates an AI model for recognizing objects in images.

## Technologies
- Python 3
- PyTorch

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/duongtri3007/fruits_detection_project.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## ▶️ Usage

Run the application with:

```bash
python main.py
```
